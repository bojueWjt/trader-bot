# report-G3-estimand-partial-exit：部分出场的 estimand 选择（B16 联合提案，G3 侧）

状态：合成路径 + 真实括号/真实波动；只描述，不作真实数据声明（`G-STAT-CLAIM` pending）。复现脚本 `estimand_b16.py`，原始数据 `estimand_b16.json`。

## 1. 问题

G1 真实 `gold` 的 67 条计划里 **40 条是三档止盈梯**（平均 2.22 档，分数留空即等分），完全平仓必须打满全部档位或被 SL 收掉。于是"是否可评估"主要由**梯子走完要多久**决定，而不是由信号是否兑现决定。两种 estimand：

- **A（现行实现）**：观察终点未完全平仓 → 整条右删失，`net_R=null`，排除出分母。
- **B（终点强制平仓）**：以 `horizon_end` 的 mark 价结算余仓，每条都可评估。

## 2. 实验

真实括号（SL 中位 1.75%、末档 TP 中位 5.71%）、真实 BTC 波动（σ=3.18%/日，ETH ×1.25、其余 ×1.5 为假设）、`research_horizon_s = 5d`（B16 定值）、每条计划 120 条 1 分钟步长路径，共 8040 条。R 以 `|entry − stop|` 为单位。

| 指标 | A（删失口径） | B（终点结算） |
|---|---:|---:|
| n_evaluated | 7736（96.2%） | 8040（100%） |
| 右删失排除 | 304（3.8%） | 0 |
| 全样本均值 R | −0.0103 | +0.0528 |
| **A 丢弃的那批在 B 下的均值 R** | — | **+1.6581** |
| 丢弃批 vs 保留批：末档 TP 中位 | 17.96% vs 5.57% | — |
| 丢弃批的已实现部分均值 | +0.7151（已打掉的档位） | — |

**A 丢弃的不是随机样本，是"正在赢的宽括号单"**：它们平均已实现 +0.72R、若结算到终点均值 +1.66R，却因为最后一档没到而整条被判为"无标签"。

## 3. 决定性证据：θ 在两种口径下符号相反

同一候选规则（跳过末档 TP 宽于中位的机会）、同一批数据：

| 口径 | 基线均值 R | 候选均值 R | θ |
|---|---:|---:|---:|
| A（删失） | −0.0103 | +0.0177 | **+0.0280** |
| B（终点结算） | +0.0528 | +0.0194 | **−0.0334** |

机制：A 只保留"已完全平仓"的宽括号单，而宽括号里先走完的多半是**打到 SL 的输家**（SL 只有 1.75%，先触概率高），赢家还在路上被删失。于是"跳过宽括号"在 A 下像是好规则，在 B 下是坏规则。**estimand 的选择可以翻转研究结论的符号**，不是记账细节。

## 4. 提案：主口径取 B，A 作敏感性

- **主 estimand = B（观察终点 mark 价强制平仓）**，理由：
  1. A 的丢弃是系统性的且与候选规则相关（宽括号、长梯子、走得慢），正是 §7.4 与合并稿 C.3 要堵的幸存者偏差通道；§3 表明它会翻转 θ 符号。
  2. B 下右删失趋零，删失不再与"梯子档数"这一**计划书写习惯**耦合——θ 的可比性不再取决于作者写几档。
  3. B 的代价是显式的、可审计的：θ 的含义变为"持有至观察终点（5 天）的收益"，估值约定进 `policy_hash`；mark 价过旧（`MARK_STALE`）时该机会按 §9.10.11 A15 记 `n_coverage_excluded`，**不**退回删失。
- **A 作为预注册敏感性**：每次主声明须同时报 A 口径的 θ 与两者差；若符号不一致，结论降级为"描述"，并在报告中明示丢弃批的规模与均值（本表第 3 行的口径）。
- 不建议的第三条路（"按已实现部分记 R、余仓记 0"）：它把未实现收益强行记 0，等于对赢家单方面罚分，比 A 更偏。

## 5. 落地要求（G3 侧，待 G2 与 G0 确认后实施）

1. G2 `ExecutionResult` 需在未完全平仓时给出 `horizon_mark_R`（终点 mark 结算值）与 `outcome_kind=filled_closed_at_horizon`（或等价标记），并把估值约定纳入 `policy_hash`。
2. G3 `evaluate` 取 B 口径时消费该列；`exclusion_kind` 只保留 `coverage`（mark 不可用），右删失分支仅在 A 口径敏感性下启用。
3. `research_horizon_s` 的选择在 B 口径下不再由删失率驱动，仍按 `K_min` 与"持有至终点"的语义取 5 天（见 `report-G3-research-horizon-curve.md` §2–§4）。

## 6. 限制

1. 路径模型为无漂移随机游走、无波动聚集与跳空；真实的"赢家还在路上"比例与均值会不同，符号翻转的存在性不依赖具体数值，但幅度会变。
2. 波动只有 BTC 2024-01 实测，其余品种为乘子假设。
3. 本表是合成路径上的结果，不是真实频道数据的 θ；P2 声明时随 `G-STAT-CLAIM` 确认。
