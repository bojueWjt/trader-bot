# 草稿：G3 P1 功效未达标的「限制声明」（备用，待用户裁定 P1 闭合标准后启用）

状态：草稿，非规范性；数字来自 `docs/adr/report-G3-null-model.md`（合成数据、synthetic_validation），只描述，不作研究优势声明；G-STAT-CLAIM pending。

## 1. 事实

- 空模型 FPR（四种预注册机制，各 1000 次完整流程，T1 合成规模 ≈1600 簇，MC7）：条件于有搜索 replicate 的最坏界 Clopper–Pearson 95% 上界 ≤ 2.83%（阈值 7%），逐 replicate 四项结构诊断失败 0 次，全部 pass。
- 功效（δ = 0.2R/种子，π = 0.3，噪声 sd ≈ 1.77R，1000 次，MC7）：全体 34%，条件于有搜索的 774 次为 42%，最坏界 95% CI 下界约 39%，未达 GOAL-3 DoD 的 80%。规则找回率（植入候选在 ≥1 折被 selection 选中）约 48%。
- 敏感性（每格 200 次，非验收，MC7）：噪声 ×0.6 且 2400 簇时约 84%（最坏界下界约 78%，区间不足）；其余格 11%–71%；δ=0.4 且噪声 ×0.6 的格因基线 DEFF 降档大量落 T0 而更低。瓶颈在 selection：内层 max-t 只见训练窗后半段样本，且保守 DEFF 门在强效应/低噪声世界把搜索拦在 T0。

## 2. 限制声明（若采用「报告并限制声明」式 P1 闭合）

> 在 T1 档合成规模（约 1600 经济簇 / 4000 机会、噪声 sd ≈ 1.77R）下，本协议对每种子 0.2R 的真实过滤增益的全流程检出功效约 34%–42%（95% 最坏界下界约 39%，条件于实际进入搜索的 replicate）。因此：
> 1. 本协议在该规模下**不能**把"未检出"解释为"无增益"；未检出只描述为"在该功效下未检出"。
> 2. 任何 P2 真实数据研究若样本规模/噪声与该档相当，只能对 ≥ 0.4R/种子量级的效应或更大样本作检出声明；0.2R 量级的效应需预注册扩样本（≥ 2400 簇且噪声 ≤ 1.1R 的等效条件）后另验。
> 3. 上述数字均为合成世界的预注册假设下的结果，不是真实频道数据的功效；真实功效须在 G1/G2 真实接缝就绪后按实测 K/DEFF 重估。
> 4. FPR 结论不受功效不足影响：假阳性控制在四种机制下均通过。

## 3. 两条出口（供用户选择）

| 出口 | 动作 | 代价 |

| A. 限制声明式 P1 闭合 | GOAL-3 §7 DoD 的"功效 ≥ 80%"改为"功效报告 + 上述限制声明"，保留未达标记录；R-08 verify 改为断言功效数字被如实报告且限制声明存在 | P1 结论的可检出效应下限抬高到约 0.4R |
