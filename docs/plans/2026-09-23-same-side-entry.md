## 行为

- 新的独立信号仍是 `open_position`，自带 intent 与 ref。缓存里已有同向仓，或缓存为空但所内同向为已知开仓，都不再因此拒绝。
- 反向仓、加仓必须已有同向仓、HALT、幂等、名义金额上限保持原样。
- 市价、区间、两腿、三腿都写入各自的 `batch_entry_ids` / `batch_fills` / `batch_exit_ids`。保护数量只来自本计划成交净额。自己的净额为 0 时，不得退回所内合计仓位。
- 同簿已有的其它计划账本保留，不因同簿拒绝，也不接管兄弟计划或 `aos_` / `stToAg_` 手动单。
- 未分账的旧保护账与新计划共存时，不自动迁移。只看到入场 `filled_qty` 不能证明历史退出单已经结清，用它估算净额会把旧仓算大，也不清掉原有的 `protection_frozen`。这里没有权威的入场加退出完整证据，所以不做恢复、不从缓存或合计仓位猜测。共存时保留旧保护单，写下未决标记；若原来没有冻结，再冻结这本旧账的自动合计缩量和父级管理，并允许新计划单独入账。没有新计划碰到的单独旧账本不因此冻结。
- 父级管理按所属计划缩小数量，并关掉对账合计回退。异步管理在提交前登记本计划的退出单和只撤自己剩余入场；持久化被拒则回滚登记。
