## A. 样本规模与证据分级重估

### A.1 先数分母，再估规模

从 2024-01-01 至 2026-09-10（含两端）共 984 天；仅作预算情景，若五频道各有 600–984 个实际可见活跃日、每天 0.5–2 个去重入场种子，则为 **1,500–9,840 个种子**。这是乘法情景区间，不是置信区间；频道开设日期、停更、转发和多腿比例均未实测（低，U01）。
主估计采用频道×年份/月份分层：`N_seed_hat = Σ M_cy × p_entry_cy × b_cy × u_cy`；M 为现存普通消息数，p 为含入场提议的消息比例，b 为每条此类消息的独立计划分支数，u 为跨消息重复消除后的保留比例。管理帖、分析帖、战报分别计数，不再次增加种子；同一计划不同版本不增加种子。（P；字段可得性依据 [T1][T2]）
单频道 PoC 只能估该频道；其余四频道先用活跃日/消息密度给情景上下限，不能乘五冒充全量实测。p 的区间用随机抽样并结合人工漏检/误检校正；月块重采样给跨月波动区间，另列跨频道外推误差。不可见历史不在 M 内，未知删帖不得用 message_id 缺口直接补数。（P；[T1][T3]，U01/U02）

| PoC 1a 必测量 | 定义与输出 | 依赖/误差处理 |
|---|---|---|
| 消息数 | 普通/服务/空文/相册组件数；去重前后数；JSON、媒体各自完整率 | 固定账号权限、频道身份、起止水位；断档与服务消息不混为删帖 |
| 信号数 | 候选入场消息、计划分支、去重种子、管理消息、可组装 Episode、可评估 Episode、事件簇逐层计数 | LLM 全量初筛后用盲审纠正；「信号数」不得直接等于调用模型次数 |
| 编辑比例 | 有最后编辑时间 / 普通消息；另报入场/管理子集比例、编辑延迟分位数 | 区分字段缺失与明确无编辑标记；旧版本不可恢复不填零 |
| 图片比例 | 含图消息 / 普通消息；入场子集比例；每帖图数、可读价格图比例 | 另报媒体缺失、纯图片、图文冲突与 OCR 不可读 |
| 回复/引用比例 | 原生回复、转发来源、显式链接、文字引用分别计数；父节点可恢复率 | 显式引用也可能指分析帖；相册、讨论群映射另列 |

| 工程与人力 | 墙钟、字节、续传点、LLM tokens/拒答率、单 Episode 审核分钟数 | 用这些实测值替换 B 的估计；本表均为 P，现值均在 U01/U06/U07/U08 |

### A.2 时间证据与存活证据是两根轴

Telegram 对象说明 `edit_date` 是最后编辑日期；导出 schema 记录日期、编辑和回复等字段，但不是版本日志。删除通知亦不保证完整。因此「无编辑标记」不能自动等同于法证意义上的「从未编辑」，「有实时 watcher」也不能自动等同于零漏收。（高，[T1][T2][T3]）

| 等级 | 判定与可用版本时间 | 行为特征学习 | 结局统计 | 时间严格评估的边界 |
|---|---|---|---|---|
| V：实收版本链 | 内容/媒体哈希、实收时刻与更新顺序可追溯；`available_at` 为必需信息实际实收时间的最大值 | 可，用决策当时版本 | 可分列市场重建与原文声称的结果 | 可做主时序 cohort；仍须披露采集断档、样本选择与模型知识污染 |
| H0：历史未编辑 | 字段保真已验、无编辑标记；业务上归「从未编辑」，证据上称「未见编辑」 | 可学存活消息的风格；按发布时点的市场特征须显式接受未编辑假设 | 可做存活入场种子的市场反事实，不能叫频道全体实绩 | 可做**条件历史时序**：发布时刻+预设延迟，且上下文/媒体均有同期证据；不能冒充实测接收时延或 V 级 |
| H1：编辑过，仅最后时刻 | 当前版本及最后 `edit_date` 已知，原版本未知 | 当前表述可做结构/语言研究；不可把修改后 SL/理由作为原入场特征 | 原入场收益主统计隔离；战报仅记 `claimed_outcome` | 禁止回填初始 date。若版本与全部依赖在最后编辑时已可用可证，可研究「编辑后新决策」；否则从 snapshot 首次可证观察时刻起算，不能复活已结束机会 |
| H2：原帖缺失/删帖不可见 | 只见回复指针、转述或 ID 缺口；原因可能是删除、权限或导出缺口 | 只作缺口/引用结构，不猜原字段 | 不记胜、不记负、不记零；仅纳入缺失敏感性 | 禁入逐交易严格评估；引用里的片段只能在引用出现时成为新证据 |
| U：字段语义不明 | 导出字段未验、媒体缺失、版本冲突 | 可做不依赖缺失字段的描述 | 相关结局未知 | 拒收相应评估，保留损耗原因 |

以上用途限制均为 P；语义事实见 [T1][T2][T3]。每条同时带 `survival_scope=historical_survivor / watched_cohort / unknown`；H0 也有删帖选择偏差，不能因时间较清楚而升级总体证据。分别报告 `N_cluster_V`、`N_cluster_H0_conditional`，不得相加后声称严格样本增加。（P）
决策时刻 `t_dec=max(所需消息版本、媒体、因果链接、行情输入的 available_at)+处理延迟`。未来回复可帮助事后整理账本，但其在过去不可用的关联和信息不能进入当时特征。字段空值用显式 `unknown_reason`，布尔空状态可用 false，不能把 false 当数值零。（P）

### A.3 用 watcher 给幸存偏差做有条件的定界

1. 在获授权离线快照中，按频道×入场/管理×图文类型建立**首次观察即入组**的前瞻 cohort；以首次观察分母计算 7/30/90 天累计删除率，未到随访长度者右删失。分别统计「入场种子删除」「管理缺失」「Episode 因缺帖无法评估」，最后一种才对应收益样本选择。不能用全消息删率代替入场种子删率。（P；[T3][T4]）
2. 删帖可能晚于仓位结局；按相同随访长度把 watcher 数据裁成“伪历史快照”，检验它会删掉多少亏损/盈利种子、如何改变标签。审计采集在线覆盖、更新序列缺口、补取与定期快照差集；将捕获率下界记为 q_min。没有 q_min 的证据，删除事件数只能给发现率，不能给真实删率上界。（P；通知不完整见 [T3]；U02）
3. 对每层用发现率的区间上端 r_U，设 `d_W,U=min(1,r_U/q_min)`；只有捕获下界确实成立时才这样校正。历史删帖赔率相对 watcher 取 κ=1/2/4 三档，`d_H,U=κ d_W,U/(1-d_W,U+κ d_W,U)`；κ 为迁移敏感性参数，不是实测。历史最长约 2.7 年，短期 watcher 不能识别远期删除；对超出已观测随访的尾部风险另加 τ：`d_total=1-(1-d_H,U)(1-τ)`，τ 无可信上界时承认全总体界退化。（P；U02/U03）
4. 给定缺失比例 d，胜率的最坏界为 `[(1-d)p_obs,(1-d)p_obs+d]`；有界结果 Y∈[L,U] 的均值界为 `[(1-d)μ_obs+dL,(1-d)μ_obs+dU]`。再把存活样本统计区间、各层权重变化代入，不只画单个修正点。例：p_obs=60%、d=10% 时界为 54%–64%，不能推断删帖独立于输赢。（P，混合均值恒等式推导）
5. 原始净 R 未必有有限已知下界；可另外定义 `Y=clip(R,-2,3)` 做可复算敏感性，但必须同时披露原始尾部，不能把截尾均值冒充真实净期望。若 μ_obs=0.15、L=-2，则仅约 6.98% 的最坏缺失已能抹去正均值。删帖与亏损相关时不默认 MAR、不直接用逆概率加权“修复”。（P，代数阈值 d*=μ_obs/(μ_obs-L)；U03）

若p_obs/μ_obs只来自可评估子集，d还必须覆盖编辑、媒体缺失、拒答等排除的联合损耗；原因可重叠，不直接相加各比例。无法界定这些选择机制时，只报告可评估子集，不能把删帖敏感性当全部偏差修正。（P）
停止条件：在用户认可的 κ/τ/q_min 范围内优势翻转，结论为「存活样本有条件优势，全频道不可判定」；历史帖仍可提假设，验证转向新增前瞻研究样本。没有可迁移性证据时不得宣称幸存偏差已消除。（P）

## B. Episode 组装产线（几千条规模）

### B.1 五级处理与拒答出口

每批以不可变输入清单、schema/prompt/模型版本和内容哈希定位；重试只补失败任务，最多两次，模型调用无网络工具/代码执行权，原文内指令一律作为被分析数据。LLM 负责语义分类、字段抽取及关联裁决，确定性层负责证据、约束和拒收；双模型一致不自动成为真值。（P）

| 级别 | 输入 → 输出 | 失败模式 | 拒答/返工出口 |
|---|---|---|---|
| 1 消息版本归一 | 原始 JSON/媒体/获授权更新快照 → MessageVersion、媒体物件、缺口清单；LLM 全量类型初筛，再对候选抽结构化事件 | 秒/毫秒错位、相册拆散、图片缺字、只知最终版、噪音误判 | 时间冲突 quarantine；`not_signal / unreadable / time_unknown`；不因关键词不匹配就丢纯图帖；保留负类候选供漏检审计 |
| 2 规则链接 | 带来源锚点的事件 → 候选边列表、强/弱证据、候选 Episode 图 | 回复的是分析帖；跨频道复制；同币同向多单并存；旧单更新越过默认窗 | 原生回复/明确计划编号优先；引用片段/价格指纹次之；同频道同币同向≤72h 仅召回弱边；>1 候选不就近强并；强指针跨窗保留 |
| 3 LLM 歧义裁决 | 候选边+当时之前的有界上下文+原文/图坐标 → `link / new_episode / unresolved`、理由与引用 | 幻觉价格、事后战报反推入场、过长上下文遗漏、图文冲突 | 主模型裁决仍含歧义才交异厂商模型；最多展开一次上下文；未找到父节点、数字冲突、两路同空均拒答；分歧不能靠投票抹平 |
| 4 生命周期校验 | 事件图 → 有序 Episode、违反约束清单、可执行计划视图 | 退出早于入场、重复关闭、取消后沿用旧单、TP 数量超仓、部分退出无数量 | 校验只指出冲突，不补默认数量、不自动创造 fill；明确重开建新 Episode；拒绝项回 2/3 一次，仍失败保留 unresolved |
| 5 分层抽审 | 冻结草稿批次+盲审抽样清单 → 人工修订/接受/拒收、误差报告、批次放行状态 | 只抽一致集导致漏检；展示后续走势造成锚定；难例越积越多 | 低置信/危险类别签字后才可入组；预算耗尽则隔离剩余层，报告排除比例；不能降低门槛以消化队列 |

本表的窗口、重试次数与流程均为 P。规则链接必须保留未选边和拒绝理由。可用后续消息构建**描述图**，另编译只含 `edge_available_at≤t_dec` 的**决策图**；图的事后完整性不提高过去的可交易信息量。（P）
消息生命周期用 `ENTRY_PROPOSED → AMENDED / CANCELLED / EXPIRED / ENTRY_REPORTED → MANAGED → EXIT_REPORTED`，允许部分退出/移动 SL/撤回提议；`ENTRY_REPORTED` 和 `EXIT_REPORTED` 是作者声称。模拟器的 accepted/filled/closed 属于另一条执行状态机，两者只用显式映射关联，不能用“到了 TP1”自动创造真实成交。（P）

### B.3 人工上限、金标与放行规则

金标单位为完整 Episode（入场、管理、可观察结局及来源），不按 300 条消息折算。开发金标与冻结验收金标按时间和复制组分开；核入场字段时界面只显示当时上下文，核结局时另开结果任务。原文忠实度确认和赚钱与否完全不同。（P）

以上为 P；主验收与分层检验目标不同，**主验收的随机样本不可与定向补审混合计算总体率**。逐层 Wilson 是各层点态区间，不宣称十层联合95%覆盖；未来批次/模板的外推还需复验。抽样概率、去重规则与目标总体一并保存，收益推断另用 C/D 的经济事件簇。（P）
Wilson 取 `p_hat=e/n, z=1.96`，上下端为 `(p_hat+z²/(2n) ± z√(p_hat(1-p_hat)/n+z²/(4n²)))/(1+z²/n)`。零错时双侧上界 n=80 为4.58%、n=200为1.88%、n=400为0.951%；所以“小样本零错”不足以承诺1%。公式与方法已核对，数值本次只读计算复算。（高，[S1][S6]；通过阈值为 P）
仅在预定样本量到齐时判一次，不反复追加直到区间刚过线。任一方向/跨归属/数量级重大错误立即隔离该层；普通错误导致区间不过则修产线并用**新验收样本**重验，原错例只进开发集。若依赖/重复使有效抽样单位不足，不使用朴素 Wilson 证书，改报簇区间或不足。（P）
工作量上限估计：200×4分钟开发 + 400×2分钟主验收 + 最多800×2分钟补审 + 100×5分钟困难签字 + 100×3分钟第二人复核 + 150×3分钟漏检窗口 = **74.2 人时**；硬上限 **80人时**，不是承诺用户只需3–4小时。前50个 Episode 测中位数/P90 后重排；补审、签字和失败重验均共享上限，超额即缩小可准入层，不追加隐性人工。（低，U07；P）

### C.2 同一 DSL 与算子前视安全契约

接口为 `Hypothesis → typed AST → lint/causality → compile → feature snapshot → EventEvaluator`。DSL只接受JSON节点，不接受Python字符串；字段有单位、时钟、数据质量和最晚可用时刻。初版限制深度≤4、节点≤15、窗口集合预注册、Ref仅非负且本DSL明确Ref(0)=当前闭合值；供应商适配显式转换，禁止直接复用同名不同义函数。（P；差异实例见[Q2]）
首批算子：Add/Sub/Mul/SafeDiv、Abs/LogPositive、Compare/And、Ref/Delta、滚动Mean/Std/Min/Max/TSRank/Corr、EMA；价格可相除成无量纲，不能直接加资金费率与价格。EMA的递归初始化、Std的ddof、Rank并列秩、SafeDiv零除、缺值政策均单独版本化；缺值携带validity mask，不默认填零。（P）

| 每个算子登记字段 | 验收方式（全部适用于三种后端；P） |
|---|---|
| arity、输入/输出单位、window单位、lookback、最大lookahead=0 | 静态推导组合依赖区间；拒绝负Ref、center窗口、全样本归一化、跨资产rank、未来funding终值；未知算子拒收 |

截断和NaN测试是必要测试，不是无泄漏的数学证明；静态依赖与数据可用时间还必须验收。Polars可选择center，Qlib和AlphaGen存在可访问未来的接口，故不能把库名当“天然因果”证书。（高，接口事实[P2][Q2][A2]；测试充分性判断为P）
三种假设来源共用 `{hypothesis_id, origin=human/llm/gp, parent_ids, source_message_refs, stated_mechanism, AST, parameter_grid, created_at, viewed_data_cutoff}`。人写规则由编译器转AST；LLM只提机制/AST，不能执行任意代码；GP只改合法节点。三者用同一canonical hash去重、同一复杂度/预算/拒收原因，没有“人工假设免费试”例外。（P）

### C.3 事件级评估器及搜索账本

横截面IC回答同一时点多资产预测值与后续收益的相关性；本任务的采样单位是稀疏入场Episode，涉及未成交、管理、持有期和成本。单资产横截面无可用排序；跨时点把不同Episode拼成“横截面”也不回答本任务。AlphaGen的默认IC接口与股票轴可核对，但可替换评估器，不是整个项目必须废弃。（高，[A2][A4]；任务匹配推断为P）
定义 `EventEvaluator(AST, frozen_fold, policy, episode_set)`：仅在 `t_dec` 取特征，按冻结规则输出take/skip或预定管理决策；交既定执行语义合同生成每个候选种子的净R、成交/到期/删失状态。风险分母在入场前固定；未成交/主动skip在**每种子政策价值**口径记0，证据缺失/右删失不能记0。移动SL不重置R分母，市场反事实与真实执行校准分开。（P）
主目标为 `θ=Σw_i(R_i(candidate)-R_i(baseline))/Σw_i`，同一可评估机会集、相同成本/路径情景做配对；w由预注册去重/簇均权定义，不由模型结果选择。另报每次成交净R、coverage、成交率、尾损与H时点未闭合率；不可只比较各自入选赢家。管理变体使结局改变时必须重放，只有纯过滤才能缓存固定政策的每种子结果。（P）
入场风格模型另用合法at-risk机会集，按事先固定抽样率选“未出手”机会并校正权重，报告PR-AUC/召回/校准；几百万根K线负例不能增加正例独立簇数。若当时关注品种集合无法复原，只可谈已观察频道内的信号过滤，不能宣称学会交易员自主择时。（P；U09）

## D. 分档建模协议

### D.1 N_cluster 的可复算定义

先对同源转发、同一计划重发/多腿/多版本/管理链作must-link；再对同品种风险暴露/标签区间重叠的Episode作经济关联，图连通分量为操作性事件簇。复制可以跨频道；同币反向也不默认独立。跨品种共同市场冲击用全资产共同日历块重采样，报告不同块长下的方差膨胀；五频道不是五个独立实验。（P；块工具依据[S4]）
**N_cluster 是这种预注册规则下“可作为独立单位的候选簇数”，不因划簇就获得真实独立性。** 报原始/去重/闭合/可评估/每折purge后簇数、最大簇占比、簇大小分布、时间覆盖和块长敏感性；簇巨型化不可为了达门槛强拆。使用H0条件样本时另出一套分档，不能与V混数。（P）
以 `K=min(各实际内层训练折的N_cluster)` 决定可用档位，不能拿全历史总数定档。各训练折对冻结基线计算设计效应 `DEFF=max(1,Var_共同日历块(θ)/Var_簇独立抽样(θ))`，再取 `K_eff=min_fold floor(N_cluster_fold/DEFF_fold)` 作为额外降档信号；这是方差量级诊断，非独立性证明，也不是特征共线性VIF。不确定时取更低档，未实测前不得先许诺几千种子可做高维挖掘。（P；U06）
