### A.2 入组与缺失合同 [S02]

**N01 合同：入组捕获和删除捕获分开。** 研究数据管理员在真实1a前冻结频道/权限/观测起止、采集在线日志、更新序列缺口和补取差集的证据格式；首次实收即入组，禁止以“最终仍存活”入组。独立研究采集或另行授权的脱敏离线快照只提供各自可证明的覆盖。拿不到入组前短命帖捕获界时，默认总体明确限定“首次实收且满足证据条件的机会”，禁止报告全历史删除上界。（P02；Z N01/S02）

| 对象 | 参数、算法与退化出口（P02；Z「统计方法终判」） |
|---|---|
| 固定随访 | 分频道/入场类型，分别建成熟7/30/90日子cohort；未到期记录右删失，不算未删除；时间、图文层不混分母 |
| 删除捕获 | `r=P(发现删除｜已入组)`；`q=P(发现删除｜已删除且已入组)`；同层同随访、有证据 `q≥q_min>0` 才取 `d_W,U=min(1,r_U/q_min)` |
| 联合覆盖 | 对预注册 m 个层×随访单元，r上界、q下界各分配 `0.05/(2m)` 错误预算；另有估计界时加入总预算重新分配。两个各95%的界不称合成95%界；依赖不满足二项假设则用预定块法或不足 |
| 入组前遗漏 | 若另有遗漏比例界 `u_U`，在同一目标权重口径下才组合 `d_U=u_U+(1-u_U)d_W,U`；无界则全总体不足。独立快照不是自动完整真值，双采集捕获也不默认独立 |
| 历史迁移 | κ取1/2/4作假设网格，`d_H=κd_W/(1-d_W+κd_W)`；τ取0/0.1/0.3/1，表示既有随访终点尚未删除者的额外尾部风险，`d_total=1-(1-d_H)(1-τ)`，不重复计时 |
| 联合损耗 | 编辑、媒体、拒答、入组遗漏、删除导致不可评估等取对象集合并集；同时给原因重叠矩阵。簇均权目标的d必须是缺失权重质量，不能拿原消息删率代替 |
| 均值包络 | 固定d、有界Y∈[L,U]：`[(1-d)μ_obs+dL,(1-d)μ_obs+dU]`；胜率用L=0/U=1。若只有d上界，且观测均值在[L,U]，用d上界保守计算；观测区间和未知层权重也遍历 |
| 不可识别 | q_min=0、没有入组界、未知历史层权重或原始R尾部无界时，相关全总体结论为insufficient/平凡界；截尾R是另一个目标，不能替代原始净期望 |
| 产物与验收 | 输出cohort manifest、成熟随访表、覆盖证据、参数假设表、观测结果与二维“d×缺失结局范围”包络；合成隐藏10秒短命帖、q=0、未成熟记录、权重错配、未知尾部逐例断言退化 |

例如可见胜率60%、缺失10%时包络54%–64%；这只是条件代数。用户接受κ/τ场景不会把假设变成观测事实，行为风格同样不能免除选择偏差。（高；Z A05/统计终判；迁移适用性中）

### B.3 全窗口召回与金标

**N02 合同：全窗口概率抽样。** [S03] 审核负责人在预测前以全部频道×UTC日历6小时半开窗口建框，正/负窗口均可抽；每频道简单随机取30窗，共150窗为初始提案，每窗概率`min(1,30/W_c)`。真实入场按首次提议event_time所在窗唯一归属，多腿逐个枚举；时间不明者另列覆盖缺口，不声称全体召回。人工可前后追完整生命周期/强指针，辅助上下文不增加抽样分母。（P04；Z N02/S03）
以窗口概率倒数加权 `recall=Σ TP/π / Σ true_opportunities/π`，区间按抽样设计在频道内重采窗口簇，不能将同窗多个episode当独立二项；无真实机会时为insufficient。另从预测episode框审精度，两框不混算。验收必须含“同窗BTC识别、ETH漏掉”、多腿漏一腿、跨窗管理；所有目标真实机会有非零已知π，窗口不足全审。（P04；Z B06/S03）

**N03 合同：金标也有误差预算。** [S04] 真值负责人先冻结标注手册（提议/观察、改单/新单、方向/单位、部分退出、无法判定），开发与验收按时间/复制组隔离，标注不展示模型预测或未来走势。200个开发episode中随机50个普通例盲复标，另复核全部危险例；先报告关键字段与整episode分歧率、未决率再仲裁，不能用仲裁后零分歧遮盖原始意见。（P04；Z N03/S04）
默认金标门：普通随机复标关键字段分歧≤2%、整episode≤5%、未决≤5%；样本仅作规范稳定性门，无精度证书。主验收200例中再随机40例盲复标；发现致命分歧即暂停该批真值使用、仲裁并重验；普通分歧超过同门亦暂停。无法仲裁保留ambiguous、计未决损耗；无第二人则相关真值门not_run。阈值须在读验收结果前冻结。（P04；Z S04）

### B.4 分级放行 [S06]

抽样单位为冻结批次内去除同源重复后的唯一episode；批次边界、随机seed、n/c、错误严重度手册先冻结。普通错误定义为整episode至少一处非致命忠实度错误，一例多个普通错只计一件；任何影响方向、品种、入场归属或数量级的错归致命，不能在看结果后降级。（P04；本次要求、Z S06）

| 错误／样本层 | 放行合同与停止路径（P04；本次要求、Z B05/S06） |
|---|---|

**入场价偏离的具体算法**：取消息字段闭包的`t_a=available_at`，mark用C.1 as-of取最后可用已闭合1m值m；仅有历史1m数据时注明近似，决不取包含t_a但尚未闭合的bar收盘价。陈旧度默认≤120秒，超过即`MARK_STALE`。以该品种t_a之前30个自然日、至少10,000个有效连续1m收益计算 `s=1.4826×median(|r−median(r)|)`，缺bar不跨洞计算收益；`δ=|log(p_entry/m)|`，区间入场分别记上下端δ并用距m最近端作告警指标。（P05；本次要求；因果约束Z S01/S09）
阈值分两层，各自回答不同问题（**2026-09-11 Claude 验收修补**：原稿单一阈值 `k×s×sqrt(h)` 把"标记价陈旧容差"和"计划入场价允许离现价多远"混成一个量。h 通常为 1 分钟，BTC 1m 稳健波动率约 0.05%，k=20 也只有约 1%，而交易员的挂单入场离现价 2%–8% 是常态，按原阈值绝大多数限价入场都会进隔离，复核负担失控且抓不住真正的数量级错）：
- **数量级门**（致命类）：`δ ≥ ln(3)`（入场价与 m 相差 3 倍以上）直接 `UNIT_SCALE_CONFLICT`，必须回原文/图片定位，不自动除以 1000；这一层与波动率无关，只抓 `6.5` 当 `65000` 这类抽取错。
- **合理性带**（一般类，按频道×订单类型）：用开发窗内人工原文确认的有效入场价，计算 `δ` 的经验分布，取第 99 百分位为 `T_plaus` 并冻结（提案；样本 <50 时该层用全体频道合并分布并标 `VOL_HISTORY_SHORT` 同类的不足码）；`δ > T_plaus` 只标 `ENTRY_MARK_DEVIATION` 隔离待复核，有原文远挂单证据可签字保留。验收/测试收益不参与校准。
- **标记价陈旧容差**只用于判断 m 本身是否可用：`h` 超过 120 秒即 `MARK_STALE`，不再把 `k×s×sqrt(h)` 当入场价阈值。
历史不足不借未来波动率；小波动品种保留 `5×tick_size/m` 下限；跳空可产生真异常，不能据此删亏损样本。（P05；Z B07/C09；修补理由为高可信算术，百分位阈值为低可信提案）
