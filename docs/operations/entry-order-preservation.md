# 工作入场限价与资金占用

RESUME、换品种开仓不得以撤销合法工作入场限价来满足门禁。机器人订单身份为 `^B[0-9a-f]{32}[0-9]{2}$`；用户手动订单（包括 `aos_*`）仍禁止自动撤销。门禁与投影不一致应修复证据处理，不能通过修改交易所订单簿绕开。

- RESUME 的工作限价豁免以场上 LIMIT/GTC/regular/明确非 reduce-only 的正价量形状，加 CID 对应账户、品种一致的 approved open/add 意图为准。投影缺列或价量不一致不能否定该证据。意图 TTL 到期不撤销已经在场的 GTC；HALT/RESUME 不要求清空合法挂单。
- 开仓资金占用先取既有交易所快照中的工作单，用剩余数量乘价格；同 CID 的旧投影只作补充，不能重复计算。同一意图的三条区间腿分别计入工作名义。
- SL/TP、reduce-only 和机器人 CID 序号 ≥10 的保护单不计开仓占用。filled/canceled/expired 腿不再预留，但仍证明该腿曾发送，不能将其重新算作“尚未发送”。
- 计划仅补有明确 seq 和名义的未发送腿。旧 `entry.type=zone` 不是一腿计划，不能把场上的 02/03 判成全账户未知。只剩保护单的意图占用为零。
- 未知工作腿或不完整多腿计划按该意图 `max_notional` 保守预留，与已知工作名义去重；后续按资金是否足够决定接受或 400 拒绝。无合法风险预算等真正损坏数据仍不得凭空放行。
- 单一 operator 入口在批准符合条件的区间阶梯时保存 `type=zone_ladder`、三档 seq、价量及名义；下发使用已批准三档，不因后来价格变化重新生成。

占用读取和 RESUME 豁免均不写交易所、不改订单投影、不创建撤单命令。新开仓的授权、品种风控、账户状态和资金上限继续生效；别的品种有挂单本身不是拒绝理由。
