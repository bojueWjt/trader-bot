## 🟡 建议（不阻塞，建议在 A-T 前收紧）

1. **守卫只拦 `Dimensions.get`，拦不住 `Dimensions` 的其他入口**：`__tests__/tabletSourceGuard.test.ts:25-31`。`Dimensions.addEventListener('change', ...)` 能拿到窗口宽度，再自写阈值，这正是 §7A.1 禁止的"自写阈值"（N1 存活）；别名 `const D = Dimensions; D.get(...)` 也能绕过（N2 存活）。已经 grep 核对过：`src/` 里除了 `useWindowDimensions` 这个名字，没有任何地方引用 `Dimensions` 标识符，而 `useLayoutClass.ts` 本身也只用 `useWindowDimensions`。所以可以直接把规则收紧成"除 `ui/useLayoutClass.ts` 外，禁止出现 `\bDimensions\b`"。这一条规则同时覆盖 get、方括号、解构、别名和 addEventListener，当前代码也不会因此变红，比继续枚举写法更稳。
2. **BottomSheet 的豁免比计划写的宽**：`__tests__/tabletSourceGuard.test.ts:44`。计划 T7A-2 的豁免是"BottomSheet **高度**"，但守卫对 `ui/BottomSheet.tsx` 放开了整个 `useWindowDimensions`，在里面解构出 `width` 再自写 `>= 700` 可以通过（N3 存活）。建议对 `heightConsumer` 追加一条规则：不得解构或读取 `width`，例如禁止 `/\{[^}]*\bwidth\b[^}]*\}\s*=\s*useWindowDimensions/` 和 `useWindowDimensions\(\)\s*\.\s*width`。
3. **守卫只扫 `.ts`/`.tsx`**：`__tests__/tabletSourceGuard.test.ts:18`。在 `src/` 下新建 `.js`/`.jsx` 文件就不会被扫描（N10 存活）。`src/` 目前没有 js 文件，所以现在没有风险；如果想一劳永逸，可以把扩展名改成 `/\.[jt]sx?$/`。优先级低于前两条。

另外说明两类存活变异为什么不建议追：`6e2`、`0x258`、`1200 / 2` 属于刻意混淆，正则守卫本来就只能拦住正常写法，追下去收益很低；`onLayout` 取宽再判断是容器级测量，计划本身就要求 `EquityWaveform` 按 `onLayout` 取宽，一刀切禁止会误伤，这类问题留给代码审查。

## 💭 nit

1. 4 个测试文件被整体重排成 prettier 默认的 `{ X }` 括号空格（`bottomSheet.test.tsx:2-6`、`layoutClass.test.tsx:2`、`tabletNavigation.test.tsx:2-9` 等）。这与 `.prettierrc.js` 的默认值一致，lint 也通过，但和 `src/` 里的 `{X}` 风格不统一，而且让实质改动淹没在格式 diff 里（例如 `bottomSheet.test.tsx` 的 92 行改动里，实质改动只有 `try/finally`、宽屏安全区断言和注释）。以后建议把格式化和逻辑改动分成两个提交，或者只格式化改到的行。
2. `tabletNavigation.test.tsx:130`：第一个用例的 `unmount` 没有放进 `finally`，断言失败时渲染树会留到下一个用例。尺寸有 `afterEach` 恢复，影响只是失败时多一些噪音，而深链用例已经用了 `try/finally`，建议统一。
3. `tabletNavigation.test.tsx:40-41`：`RootTabParamList` 和 `RootTabs` 从同一模块分两行 import，可以合并。
