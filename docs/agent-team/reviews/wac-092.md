### 3.4 站点内 host 匹配器："一律失败"的实际范围（任务第 4 项）

| 变体 | verify | 说明 |

真正会失败的只有两种情况：

1. 带 host 匹配器的路由排在片段之前，而且用了白名单以外的处理器，例如 `redir`、`rewrite`、`uri`、`request_header`、`respond`、`abort`、`basic_auth`、`reverse_proxy`；
2. 带 host 匹配器的路由，不论排在哪里，只要把前缀转发到 8183 或 watcher 的端口（9090、9100）。

对生产的影响：只有 jp-bot 站点块里真的写了 `@x host <别名>` 之类的写法，才会受影响。这一点要用户确认，见 §8 的 C-2。授权清单第 70 条的措辞"做重定向之类，verify 会失败"是准确的。
