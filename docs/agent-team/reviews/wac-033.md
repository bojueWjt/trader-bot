## 3. 6 行删除是否削弱既有断言：没有

6 行删除全在 `test_http_fetch_allows_exactly_4_mib` 与 `test_http_fetch_rejects_over_4_mib_without_unbounded_read`，逐行是把 `snapshot.MAX_SNAPSHOT_BYTES` 换成字面量：

| 原 | 新 | 当前实现下等价性 |
|---|---|---|
| `MAX_SNAPSHOT_BYTES - 2` / `== MAX_SNAPSHOT_BYTES` | `4194304 - 2` / `== 4194304` | `4 * 1024 * 1024 = 4194304`（`watcher_config_snapshot.py:33`） |
| `self.sent >= MAX + 1`、`remain = MAX + 1 - sent`、`sent == MAX + 1` | `4194305` | 同上 +1 |
| `sum(reads) <= MAX + 65536` | `<= 4194304 + 65536` | 同上 |

断言的数量、方向、分块上限（`max(reads) <= 65536`）、"读到上限+1 后不再读"的守卫全部保留；只是期望值从"跟随实现"变成"钉死契约 §9.11 的 4 MiB"，严格变强。
