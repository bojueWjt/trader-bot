## 🟡 建议（不阻塞；建议在 wac-015 一并处理）

1. **恒定时间比较没有测试锁定**（`lib/auth.js:42-52`；M3/M3b 漏过）。时序无法在单元测试里可靠地测，所以应补一个结构性断言：`auth.js` 的比较路径必须经过 `crypto.timingSafeEqual`，且 token 比较处不出现 `===`/`==`；或者导出 `matchesToken`，用一个会记录调用的 `timingSafeEqual` 替身断言"对每个已配置摘要各调用一次、没有短路"。理由：R2 明确要求常量时间比较，目前换成 `===` 不会有任何测试变红。
2. **never_allowed 层没有独立测试**（`lib/auth.js:161-163`；M7/M7b 漏过）。现有断言（`__tests__/auth-media.test.js:159-163`）都命中了 browser 行，所以即使删掉 never_allowed 也会被 `identity_forbidden` 以 403 挡住。建议补两类用例：对 gateway 用未注册的 `/api/login/anything`（只有 never_allowed 能给出 403），覆盖 GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS；再对 `isNeverAllowed` 做纯函数测试。理由：R6 要求与方法无关，现在这一点只靠代码成立，测试证明不了。
3. **接线测试是文本位置比较**（`__tests__/auth-media.test.js:173-185`；M15 漏过）。在 `server.js:77` 之前随便注册一个 `app.get(...)`，测试和真实 HTTP 都不会发现。建议改成结构断言：用 resilience 测试已有的 vm/假 express 引导（或导出 `app`），断言注册的第一层就是 `watcherAuth`，且在它之前没有任何 `use`/`get`/`post`/`put`/`delete`/`all`；再补一个真实 HTTP 冒烟（`listen(0)`，本机可跑，Codex 沙箱不能绑定端口时应失败而不是跳过，否则等于测试数减少）。理由：计划 §2.1 要求"每个请求都在所有 handler 与静态文件之前校验"，目前的测试锁不住这一点。
4. **`last_message_ingested_at` 把"库不可读"与"从未入库"混为一个 null**（`lib/status.js:19-20`）。计划 §5.1 的状态条按这个字段区分"静默"与"接口失败"；库损坏或路径错误时，app 会显示"静默"，而静默不算故障，于是真故障被掩盖。建议让读取失败走可区分的通道（例如另加一个错误标记字段，或让 `/api/status` 返回错误），至少记一条不含路径以外信息的日志。另外，DB 路径解析与 `lib/trading-api.js:21-42` 的 `resolveTradingDbPath` 重复且缺冲突检查，建议直接复用。
5. **compose 没有把 `WATCHER_*` 凭据传进容器**（`bridge/docker-compose.yml`，watcher 的 `environment` 块）。现在按这份 compose 起容器，会因缺凭据退出并反复重启，这个方向是安全的。但 O-0 发行时必须补上 env 注入（六个变量，值不进仓库，不插值进 healthcheck），并在 runbook 中核对。请 Planner 记到 O-0 清单。
6. **截流日志字段不全**（`lib/media.js:121`）：契约 §9.9 要求 `request_id、filename、bytes_sent、reason`，现在只有 `filename` 和 `reason`；客户端断开（`res` 的 `close`）时也不记日志。watcher 没有 request_id 可以理解，但 `bytes_sent` 应补上。
7. **跨任务依赖**：W-0a 合入后，gateway 身份在 watcher 侧已经可以到达 `GET/PUT /api/trading/accounts...`，但第二层秘密字段拒绝与响应剔除属于 W-0b（wac-011）。在 wac-011 合入之前，集成分支不得进入任何部署候选。这不是回归（改动前 watcher 完全没有鉴权），只是一个排序约束。

3. **E-02**：已实现"≥32 字节、两两互异、未配置的 PREVIOUS 不参与匹配"。尚缺：

   - 剥离字符集应与 Python `str.strip()` 对齐；JS `trim()` 不剥离 `\x1C-\x1F`、`\x85`，差异方向同样是失败即关闭。
4. **E-05**：JS 端应恒加 `u` 标志，flags 取自生成物。现在只有 browser 的 `account_id` 按名字硬编码了 `u`（`lib/auth.js:103`）。
